# 社区老年大学课程报名与请假补课管理平台

## 原始需求

> 设计城市社区老年大学课程报名与请假补课页面，可使用 Vue 3、TypeScript 和 Pinia。学员报名书法、声乐、舞蹈、手机摄影或健康讲座时，页面记录年龄、基础水平、健康限制、报名来源、缴费和候补状态。课程开班前，工作人员根据教室容量、教师排班、乐器或材料需求和候补顺序确认名单。上课时，页面支持签到、迟到、请假、代签异常和课堂备注。若学员因病请假、临时换班、教师停课、教室冲突或材料不足，页面要把请假、补课、退费和候补联动起来。作品展示或汇报演出时，报名、排练、服装、家属观摩和现场安全也进入课程档案。课程结束后，出勤、补课、教师评价、退费和续报名建议会形成学员学习记录，社区可以据此调整下一期课程。社区还要把老年大学课程与活动室资源关联起来，判断热门课程是否挤占其他服务，以及候补名单是否反映真实需求。候补压力会影响下一期课程扩班。页面还要把课程、学员、教师和候补名单持续关联，社区处理退费、补课或续报时能看到每次请假、停课、转班和材料消耗的原因。

## 增量需求（候补转正通知）

> 增加候补转正通知。正式学员退课或长期请假后，页面按候补顺序、基础水平和可上课时间推送转正。候补学员确认后，缴费、教材、座位和教师名单同步更新；未确认则顺延下一位。候补未确认会自动顺延并保留原因。报名时要同时校验年龄、兴趣班冲突和家属代办信息，热门课程候补不能手工插队。候补转正会同步教材、座位和缴费状态。

## 技术栈

- **前端**：Vue 3 + TypeScript + Pinia + Vue Router + Element Plus + Vite
- **后端**：Node.js 22 + Express + TypeScript + PostgreSQL 16（`pg` 直连，启动时自动建表+写演示数据）
- **部署**：多阶段 Dockerfile（非 root 用户 + HEALTHCHECK）+ docker compose（app + db）

## 一键启动（Docker）

```bash
cp .env.example .env          # 可选，修改端口/密钥
docker compose up -d          # 构建并启动 app + db
docker compose ps             # 查看健康状态（app 为 healthy 后即可访问）
docker compose port app 3000  # 查看应用实际映射到的宿主机端口
```

- 宿主机发布端口由环境变量 `CC_PUBLISH_PORT` 决定（默认见 `.env.example`），仅应用服务发布到宿主；PostgreSQL 仅在 compose 内部网络访问。
- 浏览器访问：`http://localhost:<CC_PUBLISH_PORT>`（本机验证时宿主机端口为 `3051`）。
- 首次启动自动完成建表与演示数据写入，无需手工迁移。
- 停止并释放资源：`docker compose down`（加 `-v` 可清空数据卷重新初始化）。

## 关键业务流验证路径

1. 登录 `staff01` → **工作台** 查看待办（含"待确认转正"）与材料预警。
2. **课程管理 → 秋季健康讲座 → 开班确认**：查看教室容量/教师排班/材料/教室占用四项检查，确认开班生成课次。
3. **报名与候补 → 新报名**：勾选"家属代办"但不填全 → 被拦截；填全代办人姓名/关系/电话后提交成功。给书法班再报名 1 人 → 自动进入候补队列。
4. **报名校验**：新建一名 46 岁学员报名 → 年龄校验拦截（50-85 岁，舞蹈类≤80）；给已报摄影班的学员再报周四同时段课程 → 兴趣班冲突拦截。
5. **候补转正通知**：书法班对一名已录取学员点"长期请假"或"退课" → 系统按候补顺序自动推送转正通知（曾被顺延/时间冲突者自动跳过，原因保留）；到 **报名与候补 → 转正通知** 页对吴永强点"确认转正" → 座位号、缴费状态、教材库存、教师名单同步更新；点"顺延" → 填写原因后自动推送下一位。
6. **热门课程限制**：书法班候补 ≥3 人属热门课程，名单上的"转正"按钮被拦截（403），只能走转正通知按顺序录取；候补 <3 人的课程仍可手动破格（需填原因）。
7. **课次考勤**：选书法班第 2 次课 → 标记签到/迟到/请假/代签异常（代签异常必须填备注）→ 保存 → 登记材料消耗。
8. **请假与补课**：批准张美华的病假 → 自动生成补课单 → 在"补课安排"页安排到后续课次；学员在补课课次签到后补课自动完成。
9. **停课联动**：考勤页对某课次执行"停课处理"→ 选"安排补课"（自动追加补课课次）或"按次退费"（自动生成退费申请）。
10. **退费与转班**：审核冯建华的退费申请；办理一次转班（原班空出名额自动推送转正通知）。
11. **展演活动**：将汇报演出标记"已举办"→ 填写归档小结"已归档"（进入课程档案）。
12. **结课**：课程详情对书法班执行"结课并生成学习记录"→ **学员档案 → 学习记录** 查看出勤率/教师评价/退费/续报名建议。
13. **资源与规划**：查看活动室挤占分析、候补需求真实性（缴费率）、采纳系统扩班建议生成下期规划。
14. **流水档案 / 报名时间线**：任意报名记录点"时间线"，查看该学员每次请假、停课、转班、材料消耗、退费、转正通知的原因。

## 本地开发

```bash
# 后端（需本地 PostgreSQL，或先 docker compose up -d db）
cd server && npm install && npm run dev     # http://localhost:3000
# 前端
cd web && npm install && npm run dev        # http://localhost:5173（代理 /api 到 3000）
```

├── .env.example
├── server/                 # Express + TS 后端
│   └── src/
│       ├── schema.sql      # 全量建表语句（幂等）
│       ├── seed.ts         # 演示数据
│       ├── domain.ts       # 开班/候补转正/学习记录等核心领域逻辑
│       └── routes/         # 课程/报名/考勤/请假补课/退费转班/材料/展演/分析/流水
└── web/                    # Vue3 + TS + Pinia 前端
    └── src/views/          # 工作台/课程/报名/考勤/请假补课/财务/学员/展演/资源规划/流水
